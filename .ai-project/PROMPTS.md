# Prompts

## Builder Prompt Pattern
You are working in this repository. Read `.ai-project/PROJECT.md`, `.ai-project/STATUS.md`, `.ai-project/ROADMAP.md`, `.ai-project/DECISIONS.md`, `.ai-project/AGENTS.md`, and `.ai-project/TASKS.md` before changing code. If the work makes the app runnable, follow the "Making This App Runnable In Project Foundry" conventions in AGENTS.md.

Return:
- A short plan
- The files you expect to touch
- The implementation
- Verification results
- Any follow-up risks

Respect the permission gates in `.ai-project/AGENTS.md`.
